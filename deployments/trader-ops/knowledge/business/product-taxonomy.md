# 产品分类与业务线

本文定义产品的分类维度、业务线含义与多空产品规则。本文只描述**长期稳定的分类方案**；某个产品当前取哪个分类值、归属哪台 colo 属于动态状态，必须实时查询。

## 分类维度（`Prod_Infor` 字段）

`Prod_Infor` 用三个字段描述一个产品；多空产品由 `Index` 列的取值派生，不是独立字段。

| 分类标识 | 维度 | 字段 | 取值 | 含义 |
|---|---|---|---|---|
| `Index` | 产品线 | `Index` | 业务线标识，见下文；另有特殊值 `LS` | 同一产品线的产品 `Index` 列相同。不同产品线对应不同股指，或对应多个指数按不同比例混合的指数。 |
| `Dual` | 中心类型、单双中心 | `Dual` | `0` / `1` | `0` 为单中心：`Colo-SZ` 与 `Colo-SH` 两列是同一个 Colo 名，只有一台交易机。`1` 为双中心：两列是两个不同的 Colo 名，通常为深圳、上海各一台，例如 `CFDC3` 的两个 Colo 是 `cf-sz-7`、`cf-sh-7`。 |
| `Type` | 管理类型 | `Type` | 自营 / 资管 | 同一 `Type` 的产品归为一类。 |
| `LongShort` | 多空类型产品 | `Index` | `LS` | `Index` 列为 `LS` 的产品是多空产品，见下文。 |

## 多空产品（`LongShort`，`Index = LS`）

`Index` 列为 `LS` 的产品是多空类型产品，分为多头与空头两种：

- **空头产品**：与一个多头产品一一对应，产品名是多头产品名加上 `SHORT` 前缀。例如多头产品 `MSLS1` 对应的空头产品是 `SHORTMSLS1`。
- **多头产品**：没有额外的命名特征。注意并非每个多头产品都有对应的空头产品。

## 业务线（`Index` 列取值）

下表的业务线标识是 `Index` 的权威写法；调用 `mcp__bssh-ops-remote__list_colos_for_index` 时使用这些标识。

| 业务线 | 中文名 | 对标或构成的指数 |
|---|---|---|
| `ALL` | 全市场 | 中证500 |
| `ZZ500` | 中证500 | 中证500 |
| `ZZ1000V1` | 中证1000 | 中证1000 |
| `HS300` | 沪深300 | 沪深300 |
| `ZZA500` | 中证A500 | 中证A500 |
| `ZZ800` | 中证800 | 中证800 |
| `ZZHL` | 中证红利 | 中证红利 |
| `ZZQZ` | 中证全指 | 中证全指 |
| `ZZ2000` | 中证2000 | 中证2000 |
| `BZ50` | 北证50 | 北证50 |
| `MIX13` | — | 沪深300 与中证1000 按 3:7 混合 |
| `MIX12` | — | 沪深300 与中证1000 按 5:5 混合 |
| `MIX11` | — | 沪深300 与中证1000 按 8:2 混合 |
| `MIX6` | — | 沪深300 与中证500 按 5:5 混合 |

| `LS` | — | 多空产品，见上文「多空产品」一节 |

## 操作约束

- 双中心产品通常不单独操作其中一台机器，而是同时对两台机器操作。操作流程见 `skills/bssh-ops/SKILL.md` 的产品级操作一节。
- 如果确实只需要操作双中心产品中的一台，必须先获得用户确认。
